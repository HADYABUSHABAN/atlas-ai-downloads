# ATLAS AI

Official ATLAS download and preview information.

## التنزيل

- **Windows:** حزمة تجريبية قيد تجهيز رابط الإصدار. ستظهر الملفات المنشورة في [Releases](https://github.com/HADYABUSHABAN/atlas-ai-downloads/releases).
- **Android وiOS:** يجري تطوير تطبيق هاتف مستقل يستخدم حساب أطلس نفسه ومحادثاته المتزامنة. لا توجد نسخة منشورة في Google Play أو App Store حاليًا.

لكل شخص حسابه الخاص. نسختا الكمبيوتر والهاتف تتصلان بخدمة الحسابات؛ رابط المعاينة المحلي على جهاز المطوّر ليس رابط تنزيل أو خدمة عامة.

## Preview status

Windows builds are experimental. Clean-device acceptance and trusted publisher signing are still pending. Mobile store releases are not available yet. Platform availability will be updated here when verified downloads exist.

This repository contains download information only. Application source, owner credentials, sessions, recovery archives, personal device addresses and user data are excluded. A source ZIP generated by GitHub is not the Windows application.
